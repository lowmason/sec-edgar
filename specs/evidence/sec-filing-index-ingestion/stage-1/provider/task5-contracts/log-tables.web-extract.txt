L24: # ContainerAppConsoleLogs
L25: 
L26: Feedback
L27: 
L28: Summarize this article for me
L29: 
L30: ## In this article
L31: 
L32: Logs generated by Container Apps within a Container App Environment. This includes logs generated on the stdout or stderr streams by all containers in the app. It also includes all Dapr sidecar container logs but does not include any system or platform level logs produced by the Container App Environment itself.

L40: Basic table support  | Yes

L42: DCR workspace transformation support  | Yes
L43: Ingestion API support  | No
L44: Sample Queries  | -

L46: Column  | Type  | Description

L49: ContainerAppName  | string  | The name of the Container App generating this log.
L50: ContainerGroupId  | string  | The ID of the container's pod (Container App replica) generating this log.
L51: ContainerGroupName  | string  | The name of the container's pod (Container App replica) generating this log.
L52: ContainerId  | string  | The ID of the Container App generating this log.
L53: ContainerImage  | string  | The image used in the container instance that generated this log.
L54: ContainerName  | string  | The name of the container generating this log.
L55: EnvironmentName  | string  | The name of the Container App Environment generating this log.
L56: _IsBillable  | string  | Specifies whether ingesting the data is billable. When _IsBillable is `false` ingestion isn't billed to your Azure account
L57: JobName  | string  | The name of the kubernetes job running inside a managed AKS environment generating this log.
L58: Location  | string  | The location of the Container App generating this log.

L64: Stream  | string  | The stream where the log was emitted.
L65: _SubscriptionId  | string  | A unique identifier for the subscription that the record is associated with
L66: TenantId  | string  | The Log Analytics workspace ID
L67: TimeGenerated  | datetime  | Time (UTC) when the log was generated.
L68: Type  | string  | The name of the table

L30: ## In this article
L31: 
L32: Platform Logs generated by a Container App Environment. These logs are generated by system components and any underlying infrastructure. Events related to revision management, Dapr, Keda and Envoy can be found here.
L33: ## Table attributes
L34: 
L35: Attribute  | Value
L36: --- | ---
L37: Resource types  | microsoft.app/managedenvironments
L38: Categories  | Audit, Azure Resources
L39: Solutions  | LogManagement
L40: Basic table support  | No
L41: Auxiliary / Lake table support  | No
L42: DCR workspace transformation support  | Yes
L43: Ingestion API support  | No
L44: Sample Queries  | -
L45: ## Columns
L46: Column  | Type  | Description
L47: --- | --- | ---
L48: _BilledSize  | real  | The record size in bytes
L49: ComponentName  | string  | The name of component name.
L50: ComponentType  | string  | The type of component such as SpringCloudConfig, SpringCloudEureka, etc.
L51: ContainerAppName  | string  | The name of Container App generating this log.
L52: ContainerName  | string  | The name of the container generating this log.
L53: Count  | int  | How many times this log has been seen.
L54: EnvironmentName  | string  | The name of the Container App Environment generating this log.
L55: EventSource  | string  | The name of project generating this log. This includes but is not limited to systems components in the Container App Environments or open source integrations such as Keda or Dapr.
L56: _IsBillable  | string  | Specifies whether ingesting the data is billable. When _IsBillable is `false` ingestion isn't billed to your Azure account
L57: JobName  | string  | The name of the Job generating this log.
L58: Location  | string  | The location of the Container App generating this log.
L59: Log  | string  | The log generated by the Container App Environment.
L60: OperationName  | string  | The name of the operation generating this log.
L61: Reason  | string  | The reason why this event was generated.
L62: ReplicaName  | string  | The name of Container App replica generating this log.
L63: _ResourceId  | string  | A unique identifier for the resource that the record is associated with
L64: RevisionName  | string  | The name of the revision generating this log.
L65: SourceSystem  | string  | The type of agent the event was collected by. For example, `OpsManager` for Windows agent, either direct connect or Operations Manager, `Linux` for all Linux agents, or `Azure` for Azure Diagnostics
L66: _SubscriptionId  | string  | A unique identifier for the subscription that the record is associated with
L67: TenantId  | string  | The Log Analytics workspace ID
L68: TimeGenerated  | datetime  | Time (UTC) when the log was generated.
L69: Type  | string  | For events emitted by the Container App Environment. Type indicates the severity level of the event.
