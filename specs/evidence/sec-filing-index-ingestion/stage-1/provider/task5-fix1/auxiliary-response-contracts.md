# Selected-version auxiliary REST response contracts

Fix1 documentation checkpoint. Every row supplements the exact resource version and PUT ARM path in azure-contracts.md. GET reads exactly that same resource path, with the same api-version; role assignments/definitions and diagnostics use their exact scope/resourceId extension paths rather than an RG suffix. All methods use HTTPS management.azure.com and ARM audience. Sources are current official selected-version REST references or the publisher's versioned Swagger source. The retained response/model excerpts are claim evidence, not actual deployed responses.

Each successful model is a single resource object, never a collection/value wrapper. Field lists below describe selected configuration/readback-relevant schema, not required/non-null guarantees for every field. Optional fields may be absent. A documented create/update success or accepted async status is not evidence of effective configuration, permissions or worker success. Each actual response, provisioning completion and readback remains Stage7.

All rows have documented error response models: ADF and Storage Table/UAMI use CloudError; selected environment/account/container/assignment/definition/registry/workspace/logtable/diagnostics/actiongroup use ErrorResponse; ScheduledQueryRule uses commonMonitoringTypes.json#/definitions/ErrorContract. Other-status/error responses must not be treated as success. No async header definition in a selected response table/source means it is not a promised header here, not a guarantee that an actual response can never carry additional provider headers. Standard request/correlation/rate-limit headers appearing only in examples are examples, not required protocol fields. Generic ARM async validation/observation applies when a defined async header is returned; it does not supply missing resource-specific worker correlation.

Selected-version REST pages for actiongroup/logalert were inaccessible; the correctly relocated official publisher Swagger files explicitly declare these exact versions, paths, PUT/GET responses and models. Old-layout raw404s and failed page retrievals are retained, not silently discarded. Publisher `main` URLs are mutable retrieval locations; retained excerpts/hash/time identify the investigation observation rather than a pinned repository commit.
