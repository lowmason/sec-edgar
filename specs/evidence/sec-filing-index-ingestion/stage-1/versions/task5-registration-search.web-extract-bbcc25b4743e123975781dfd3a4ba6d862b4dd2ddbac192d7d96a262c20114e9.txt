Como resolver

    1. Verifique se você tem a função necessária na assinatura Você precisa ter uma das seguintes funções:
       * Owner (Proprietário)
       * Contributor + permissão específica
       * User Access Administrator

    2. Peça para um administrador registrar o provedor manualmente Se você não tem as permissões necessárias, peça para alguém com permissão rodar este comando no Azure CLI ou PowerShell:

        `

       * Vá até "Assinaturas"
       * Selecione sua assinatura
       * Clique em "Provedores de recursos"
       * Procure por Microsoft.MachineLearningServices
       * Clique em Registrar
    3. Confirme com o administrador da assinatura se sua conta tem acesso correto Se estiver usando uma conta corporativa ou educacional, pode ser que o Azure esteja com restrições de política que bloqueiam a criação de certos tipos de recursos.
